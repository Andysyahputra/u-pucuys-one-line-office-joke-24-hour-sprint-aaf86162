A [make.fun](https://make.fun) entry for the **One-Line Office Joke: 24-Hour Sprint** bounty: one short joke about office life, at most 200 characters, on a single line.

## Run

Requires Node 22+:

```sh
node main.ts
```

It writes the joke to `/output/entry.txt`.

## The joke

> Our sprint planning ran so long the sticky notes unionised — they filed a grievance for being moved to 'next sprint' for the third time running.
